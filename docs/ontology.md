### movimientos_netos

Entries minus issues per article in a year, in base units. Cancelled movements and their reversals are excluded; transfers and adjustments are not counted.

- Synonyms: movimientos netos, entradas menos salidas, flujo neto
- Parameters: `year` (2000-2005)
- Defects handled: SIC-04, SIC-11, SIC-12, SIC-14, SIC-18

```sql
SELECT m.art,
       SUM(
         CASE WHEN m.tipo IN ('E', 'I') THEN 1 WHEN m.tipo IN ('S', 'O') THEN -1 ELSE 0 END
         * ABS(m.cant)
         * CASE WHEN m.uni = 'CJA' THEN COALESCE(NULLIF(a.factor, 0), 1) ELSE 1 END
       ) AS neto
FROM invmov m
LEFT JOIN invart a ON a.clave = m.art
WHERE m.cancel IS DISTINCT FROM 'C'
  AND COALESCE(m.ref, '') NOT LIKE 'CANC-%'
  AND m.fecha BETWEEN '{year}0101' AND '{year}1231'
GROUP BY m.art
ORDER BY m.art
```
